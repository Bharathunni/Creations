# creations

Things I've built as a Chartered Accountant who ships software. Each project lives in its own repository with its own README; this page is the index.

The common thread: **AI to build fast, deterministic logic where the numbers must be exact.** Every tool below classifies, matches and reconciles with explicit, auditable rules, so the same input always gives the same answer and every output can be traced to the rule that produced it.

| Project | What it does | Stack | Links |
|---|---|---|---|
| **[Portfolio Filings Monitor](https://github.com/bharathunni/portfolio-filings-monitor)** | Watches a stock portfolio against BSE corporate filings every morning, keeps only material events (auditor exits, defaults, pledges, results, capital actions), ranks them by severity and emails each user a headline-first digest. Runs unattended. | Python, GitHub Actions, Google Sheets, SMTP | [Code](https://github.com/bharathunni/portfolio-filings-monitor) · [Sample output](https://github.com/bharathunni/portfolio-filings-monitor#readme) |
| **[FinBuddy](https://github.com/bharathunni/finbuddy-bookkeeping)** | Offline-first double-entry bookkeeping: vouchers, trial balance, P&L, balance sheet, audit trail. Bank CSV import with exact-match duplicate detection and reconciliation that shows the unaccounted difference to the rupee. | React, Vite, Capacitor (Android) | [Code](https://github.com/bharathunni/finbuddy-bookkeeping) · [**Live demo**](https://bharathunni.github.io/finbuddy-bookkeeping/) |
| **GL Anomaly Detection** *(in progress)* | Anomaly detection over a synthetic 36-month general ledger, built on shareable data rather than anything confidential. | Python | Coming soon |

All public repositories use synthetic or illustrative data only. No client, employer or personal financial data.
